# 故事化宣发打法(公开宣发案例拆解)

> 来源:Framia 官方在 X / TikTok 公开发布的宣发内容(如世界观短剧《瞳染》)的观察拆解。核心结论:**官方自己的宣发不是功能演示,而是"故事承载卖点"的短剧**。

## 方法论(5 层)

1. **世界观先行,做系列 IP 不做单条。** 官方宣发围绕自建世界观与固定角色展开,单支视频是 IP 的一集——关注转化靠系列化,不靠单条爆发。
2. **每支视频是一个有悬念+反转的完整小故事。** 钩子(风潮/事件)→ 悬念(主角察觉异常)→ 追查(中段)→ 反转(真相)→ 收束。**不是空镜 MV**。
3. **人物 + 台词驱动信息传递。** 观众靠对话和字幕理解剧情,不靠发布文案。零文字零语音的视频在信息流里等于没有内容。
4. **卖点藏进分镜,不说教。** 把"必须要带到的卖点"拆进分镜表,每幕绑一个卖点——观众看完故事自然见证了能力,而不是听了一遍参数。
5. **制作管线:确认制。** 世界观 → 视觉参考 → 场景图确认 → 角色一致性资产 → 分镜表(含"对应卖点"列)→ 逐镜生成确认。每一步确认后再往下走,返工成本最低。

## 反模式(空镜 MV 教训)

- N 个漂亮但无关联的氛围空镜,没有人物、事件、因果链 → 观众 3 秒不知道在看什么就划走;
- 零文字零语音零字幕,信息全靠发布文案 → 短视频用户先看画面,画面无信息 = 无内容;
- 核心概念(如"A vs B 对决")没有可视化:无对比、无胜负、无冲突;
- 单镜头技巧(如换屏特效)再好,和全片没有叙事关系也救不回来。

**判据:只看画面静音播放,一个陌生人能否说清"这视频讲了什么"?不能 = 不及格。**

## 迁移到推广短视频的叙事结构模板

把"干巴巴的产品点"改造成故事三幕:

1. **第一幕=冲突前置**(第 1 帧):主角遇到一个问题/挑战/对决;
2. **第二幕=过程展示**(卖点自然发生):解决问题的过程恰好展示产品能力(每个分镜绑一个卖点);
3. **第三幕=反转/争议收尾**:结果出人意料或没有标准答案 → 评论区站队。

## 节奏参考

- 蹭新模型/新功能发布的热点窗口是官方验证有效的打法("热门模型第一时间追热"互动明显更好);
- 系列化更新比单条精品更重要:同一世界观/同一主角持续出集,关注转化才发生。
