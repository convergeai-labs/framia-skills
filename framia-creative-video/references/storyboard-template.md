# Storyboard 模板与场景设计规则

Storyboard 是不花 credit 阶段最便宜的纠错工具:在这里改一行字,比在生成后重拍一条 clip 便宜两个数量级。

## 模板

```markdown
# <项目名> Storyboard
> Format: 9:16 vertical / 时长 / fps / 披露语
> as of <日期>

## Creative brief
- Audience:
- One-line promise:           # 一句话,观众看完记住什么
- Memory image:               # 全片最强的一帧
- Emotional arc:              # 如 等待→结盟→崛起→逆境→决胜→加冕
- Visual rule: 生成素材只负责运动与氛围;文字/事实/披露全部确定性 overlay
- Continuity:                 # 主角外形/服装/号码/色调的跨镜不变量

## Scene plan
| 时间 | 节拍 | 原生画面 | 运动契约 | 精确 overlay | 生成风险 |
|---|---|---|---|---|---|
| 0–4s | ... | ... | 必须有什么在动:主体/布料/镜头/环境 | `...` | 低/中/高 |

## Persistent packaging
- 披露语、调色板、文字安全区(避开底部播放器控件)、结尾 hold 时长

## Acceptance gate
- [ ] 每镜有原生主体/环境/镜头运动(无静态图推拉)
- [ ] 主角跨全片可辨识、形象一致
- [ ] 逐场景的特殊验收点(如"球出手时球体保持圆形")
- [ ] 无意外事实断言(虚构内容不被读作真实新闻)
- [ ] 时间线:N 条 clip + 连续 BGM,总时长/比例正确
- [ ] 导出通过常速播放、contact sheet、black/freeze/silence 检测
```

## 运动契约(motion contract)

每场必须写明"什么在动"。这是防"静态图幻灯片"的验收依据:生成结果里找不到契约规定的运动 = 该镜失败,不因"画面好看"放行。可用的低成本动感来源:蒸汽/烟、灯光扫动、雨/雪/彩带、布料、镜头推拉摇移、人群背景。

## 场景设计的能力边界(重要)

按生成难度分级,剧本为高成功率让路:

- **低风险**:单主角中远景;背影/剪影;纯氛围空镜;蒸汽/彩带/灯光;慢推/拉/摇镜。
- **中风险**:单主角+一个道具(球、毛巾);运球/出手等规范动作;面部中近景情绪戏。
- **高风险(尽量避免或拆镜)**:多人身体交互(拉人、拥抱、对抗);复杂球体物理特写;手部精细动作;精确手持物(奖杯要"通用金色奖杯",不要精确造型);可辨认的真实地标/ logo / 文字。

实测案例:某 v7 项目的"队友拉起倒地球员""多人防守轮转+跳投""队友环绕举奖杯"三场全部生成失败,最终靠重剪旧素材兜底——高风险场景要么改写成单主角等价情绪(跌倒→独坐场边毛巾搭头抬眼),要么接受它会烧掉多倍重试预算。

## Prompt 写法要点

- 参考图只用于主体一致性,场景、动作、镜头、光线全部文字描述;
- 负面约束写全:no readable text / scoreboard / logos / watermark / dialogue / slow photo zoom / anatomy mutation;
- 涉真人时从第一版就用虚构化表述(fictional, unbranded, indoor-only),不要等 5001 再改;
- 每场结尾指明"最后一帧"的构图(hero pose / 定格点),方便剪辑对齐。
